# /public/photos/

Drop **real on-the-job photos here only.** Do not place stock or AI-generated
images that imply they're real completed jobs — that misrepresents the
business and can violate FTC truth-in-advertising rules.

Suggested filename pattern (improves SEO):
- `washer-repair-residential.jpg`
- `dryer-repair-technician.jpg`
- `refrigerator-repair-on-site.jpg`
- `gas-stove-repair-residential-kitchen.jpg`

When images are added, use them via `next/image` with descriptive `alt` text
that describes what is actually shown — not stuffed with keywords.
